# Qline v1.11.1

**Security fixes, new Terms of service and Privacy policy, and a UX/accessibility pass.**

- **Security.** Signing in with Google can no longer be used to take over an account someone else pre-registered with your email: the old password and sessions are removed first. Platform-admin access now needs a verified email. See [docs/29](../29-AUDIT_2026-11-21.md).
- **Terms and privacy in the app.** Settings → Terms of service and Privacy policy (version 2026-11-21), readable before signing in and offline. The sign-in screen says what you agree to. Settings → Delete account explains what is deleted and sends the request.
- **Easier to use with large text.** Home, Lead inbox, Work and Business no longer clip or overflow at 1.3× and 2× text. Filter rows fade at the edge when there is more to scroll.
- **Screen readers.** Tappable cards are read as one labelled button (the Content Studio Drive card was announced without a label).
- **Haptics.** A light tick on the main decision button of a screen (like Approve) and a firmer one on destructive actions. Android skips it when touch feedback is off.
- **Smaller fixes.** "Business" and "Projects" stay on one line, the Integrations summary lists current services, sign-out text is right for Google accounts, and a lone device shows a note instead of a disabled red button.

**Server:** production runs API 1.11.1 (Neon function deployment #18). No database migration.

**This is the first release you can install from inside Qline.** On 1.11.0, open Settings → App updates (or wait for the update notice) to test it.

**Not verified yet:** no device QA. Facebook still needs a registered Meta app.
