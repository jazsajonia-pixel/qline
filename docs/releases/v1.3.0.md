## Qline 1.3.0

**APK:** `qline-1.3.0.apk` (versionCode 4).

> **Uninstall Qline 1.2.0 or older first.** This release is signed with a new release key. The old key wasn't available, so Android won't install 1.3.0 as an update. Your workspace data is kept on the server; just sign in again. Later versions will update normally.

### What's new
- **Live AI sends by itself.** Stop talking and your message goes on its own, with no Send tap needed.
- **No captions.** While Qline speaks, the orb pulses and ripples on each word.
- **Chat moved below the orb**, so messages no longer cover it.
- **5-second launch animation.**
- **Continue with Google** sign-in.
- **The assistant can do more:**
  - search and read your Gmail or Outlook
  - list and create calendar events
  - build a Google Form from chat and give you its link, and read the answers
  - create Sheets
  - add contacts
  - list leads, approvals and workflows, and run workflows
  - post to Slack
  - send you a notification

  Sending, posting, adding contacts and running workflows always ask for your approval first.
- **Phone notifications** for important emails, new leads, approvals and assistant reminders, plus a new Notifications screen.
- **New automations:** important email → task, overdue nudge, evening wrap-up, and a weekly review.

### Known limits
- Phone notifications only arrive while Qline is open or running in the background. Alerts when the app is fully closed need push notifications (Firebase), which aren't set up yet.
- Until Google verifies the app, the Google sign-in screen shows the server's domain instead of "Qline". Gmail access also shows Google's "unverified app" warning.
- Not yet tested on a physical phone.
