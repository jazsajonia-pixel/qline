# Qline v1.11.0

**Faster live voice that understands Taglish, Live AI that keeps going in the background, Facebook Pages posting you approve, and in-app updates.**

- **Voice v2.** Qline starts speaking while the answer is still being written, understands Filipino–English, lets you interrupt by talking ("teka", "wait", "stop"), and has a listening-language setting. See [docs/26](../26-VOICE_V2_AND_CONTINUITY.md).
- **Background continuity.** Minimize Live AI or leave a chat and the answer and voice keep going. The voice orb flies into the navbar icon, which shows listening, thinking, speaking, idle or disconnected.
- **Fuller answers.** Replies add the useful context (why, what it depends on, the main caveat, the next step) without padding.
- **Facebook Pages.** Connect your Pages, write text, link, photo or video posts, post now or schedule them, see their status and cancel scheduled ones. Nothing is posted until you approve the exact post; posts the AI writes wait in Approvals. Facebook only. See [docs/27](../27-FACEBOOK_PAGES.md).
- **In-app updates.** Qline tells you when a new version is ready and never forces it. Tap Update: it downloads, checks the file, Android asks you to confirm, and Qline reopens by itself (or with a tap on a notification). See [docs/28](../28-IN_APP_UPDATES.md).

**Server:** needs API 1.11.0 with migration 0026.

**Not verified yet:** no device QA. Facebook has not been tried against a real Page (a Meta app has to be registered and reviewed). The first in-app update can only be tested once a release after 1.11.0 exists.
