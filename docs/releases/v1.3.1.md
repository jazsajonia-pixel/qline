## Qline 1.3.1

**APK:** `qline-1.3.1.apk` (versionCode 5). It installs as an update over 1.3.0 because it uses the same release key.

### What's in this release
- **No app changes.** The app code is the same as 1.3.0. The only differences are the version number and a new design document.
- **New design document:** `docs/14-KNOWLEDGE_OS.md` describes the planned Knowledge OS, which covers business knowledge, a knowledge map, chat context controls and safe automatic saving. It is a plan only; none of it is in the app yet.
- **The server is unchanged** and still reports API 1.3.0. The v1.4 runtime work (PRs #3–#5) is not part of this release.

### Known limits
Same as 1.3.0:
- Phone notifications only arrive while Qline is open or in the background.
- The Google sign-in screen shows the server's domain until Google verifies the app.
- Not yet tested on a physical phone.
