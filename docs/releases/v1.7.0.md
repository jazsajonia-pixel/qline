# Qline v1.7.0

**Released 2026-11-19.** [GitHub Release](https://github.com/jazsajonia-pixel/qline/releases/tag/v1.7.0).

- APK: `qline-1.7.0.apk` (versionCode 9), signed with the same Qline release certificate as 1.6.0, so it installs as an update. Size and SHA-256 are listed on the GitHub release.
- Production API v1.7.0: migrations 0013 and 0014 are applied, and Neon function `api` is on deployment #13 (bundle SHA-256 `a7330e42e429a029689055278879baa4831deb6682d8ec12c82de443f79482c8`, built from the release branch: main `80278ce` plus the version bump).
- Restore point before the migrations: Neon branch `pre-v1-7-restore-point`.
- Not yet checked on a physical device.

- **Safer actions in connected apps.** Full autopilot's daily limit now holds even when several jobs run at once. If Qline can't tell whether an action in a connected app went through (for example, the connection dropped), it never retries on its own. It lists the action under Approvals → "actions need checking" so you can mark it done or not done.
- **The AI chat picks up where you left off.** Opening the chat continues your current conversation. New chat starts a fresh one. An answer that was still being written when the app closed is shown when you come back.
- **Fewer repeated lookups.** Within a conversation, the AI reuses what it just read, for as long as it is still fresh and unchanged, instead of asking the same app again.
- **Cleaner answers.** Answers show formatted text (headings, lists, tables, code) without raw symbols, even while they're still being written. Links ask before opening.
- **A tidier activity trace.** The AI's steps fold into one line with a status: Running, Completed, Waiting for approval, Failed or Needs attention. Tap it to see the details. Approvals, failures and changes stay visible even when folded.
- **Knowledge in the chat.** The Knowledge button left of the message box opens the knowledge map over the chat. Add up to 5 entries to a message. They show as chips you can remove, and the sent message shows which knowledge it used.
- **Better knowledge map.** Zoom in and out, fit to screen, reset layout, long-press to move items (positions are remembered), search, filters, "connected only" and focus on one item.
- **Back button.** On Home, Back asks before closing Qline. On other tabs, it goes to Home. Leaving the chat with an unsent message or an upload in progress asks first.

Requires: migrations 0013 and 0014 (applied). The API changes are additive, but the 1.6.0 app was not tested against the 1.7.0 API.

Not in this release: Gemini keys (M10), OAuth timeouts and single-flight token refresh (M11), live voice (M6), Drive files and inline images in chat (M7), customization (M8) and custom agents (M9).
