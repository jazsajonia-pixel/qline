## Qline 1.5.0 — AI CEO missions

**APK:** `qline-1.5.0.apk` (versionCode 7). Signed with the same Qline release certificate as 1.4.0, so it installs as an update.

### New
- **Missions.** Give the AI CEO a goal. It proposes a plan of tasks for the specialist agents (sales, marketing, finance, operations, research). Nothing runs until you approve the plan. You can also ask for a revision or reject it.
- **Specialist tasks.** Approved tasks run in order; a task can use an earlier task's output. Independent tasks run in parallel, up to the mission and workspace limits.
- **Review.** Tasks marked "you review" wait for you to accept the output before later tasks use it. You accept or reject the final result.
- **Budgets.** Each mission has a token budget, a tool-call budget and a time budget. Spending is reserved before each call; when a budget runs out the task waits for you ("Add budget & retry" or "Skip").
- **Pause and emergency stop.** Pause holds new mission tasks. Emergency stop denies every agent, workflow and mission tool at once, cancels running mission tasks and blocks approvals until an owner or admin turns it off.
- **Trace.** Every step of a mission is recorded and shown in the app.

### Safety limits in this release
- Mission tasks can only read your data, write notes, propose memories, draft emails and notify you. They cannot send, post, publish, pay, or change or delete records; those stay with chat agents and workflows, behind approvals.
- Mission history cannot be deleted by the app (database grant).

### Server
- API v1.5.0 with migration `0008_missions.sql`. The app shows a clear message if it talks to an older server.

### Not in this release
- Knowledge OS (docs/14).
- Session-policy changes (docs/15) — still waiting for the owner's decision; session settings are unchanged.
