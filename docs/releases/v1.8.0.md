# Qline v1.8.0

**Released 2026-11-19.** [GitHub Release](https://github.com/jazsajonia-pixel/qline/releases/tag/v1.8.0).

- APK: `qline-1.8.0.apk`, 59,867,500 bytes, SHA-256 `08f4d5aa1c2a8846ebd9abf13ea0afec2d9693f163ba4e11bc63f313e5e53216`. It is signed with the same certificate as 1.7.0 (v2 signer SHA-256 `042819cb…88c1`), so it installs as an update.
- Production API v1.8.0: migrations 0015–0019 are applied, and Neon function `api` is on deployment #14 (bundle SHA-256 `e73630b39a012e11db0bcb5fcb5b5167b33810fa66ae8d8e2fbf4cb03d5e6add`).
- Restore point taken before the migrations: Neon branch `pre-v1-8-restore-point`.

- **A space just for you.** On first run you can choose "Just me". This creates a personal space with life domains: Personal, Work, Learning, Projects, Health and Money. Tasks can belong to a domain. Under Domains you can add, rename or hide them. Business spaces work as before, and you can add either kind of space from the space switcher.
- **Your own AI agents.** Create an agent based on a built-in profile. It starts paused with read-only tools. You can preview it, keep its versions and go back to an earlier one, duplicate or archive it, and set daily, concurrency and step limits.
- **More than one key per AI provider.** Keys can be named, turned off, made primary or pinned to an agent. If one key is busy or rate-limited, Qline uses another eligible key. Extra keys don't raise a provider's own limits.
- **AI proposals you approve.** The AI can propose a mission or a change to an agent. You review it, edit it if needed, then approve or reject it. Approving uses the same checks as making the change yourself.
- **Google Drive files in chat.** The AI can find your newest files, sorted by when they were created or changed. Images show inline, and other files appear as a card you can save.
- **Files you sent can be opened again.** Message drafts are kept for each chat.
- **Steadier connections.** Sign-in requests time out instead of hanging. A brief outage at a provider no longer disconnects your account, and large or malformed uploads are refused safely.
- **Sign out other devices** in Settings. Sign-in limits now apply across the whole service.
- **Voice waits for you.** In Live and hands-free mode, Qline waits a little longer when you pause mid-sentence ("…and") and replies sooner after a complete request.

Requires migrations 0015–0019. The API changes are additive.

Not in this release:
- password reset;
- choosing a domain automatically;
- domains on notes and chats;
- realtime voice.
