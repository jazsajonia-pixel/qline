## Qline 1.4.0

**APK:** `qline-1.4.0.apk` (versionCode 6). Signed with the same Qline release certificate as 1.3.1, so it installs as an update.

### What's included

- **Durable automation runtime:** persistent jobs, transactional outbox, lease recovery, retries/backoff, cancellation, dead-letter handling and idempotent schedule/event dispatch.
- **Human approval for workflow Slack posts:** the server enforces approval before a post can be sent.
- **Supervised Operations UI:** run-status overview, run history and details, background jobs, safe retry/cancel controls, and human resolution for unknown external-action outcomes.
- **Production API v1.4.0:** migration `0007_durable_runtime.sql` is applied and the Neon production API is deployed.

### Important limits

- **Knowledge OS is still design only.** The knowledge graph, chat knowledge drawer and automatic knowledge capture are not part of this APK.
- AI CEO v1.5 is also design only.
- Real Gmail/Sheets sync and real Slack posting were not verified with connected provider accounts in the preview environment.
- The APK passed CI analysis/tests/build and release-certificate verification; physical-device testing remains outstanding.
- Production scheduled workflow tick remains every 15 minutes on Neon Free.
